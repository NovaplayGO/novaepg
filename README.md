## 🧐 ¿Qué se hace en este repositorio?

Sistema automatizado de recolección, parseo y generación de Guías de Programación Electrónica (EPG). Descarga XMLs globales, los filtra para América y España, y compila el archivo comprimido `guide.xml.gz` y `novaeventos.xml.gz`.
